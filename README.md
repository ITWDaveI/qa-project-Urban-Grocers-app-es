# Proyecto Urban Grocers 
Automatización de pruebas API
Se realizaron 9 pruebas tanto positivas como negativas probando la funcionalidad de crear un kit. Para esto, se automatizo la creación de un usuario con token unico y se logro la ejecución de todas las pruebas.

## Tecnologías:

Se utilizo Python en PyCharm para la edición de las pruebas y automatización.

Se ejecutaron las pruebas con Pytest

Se uso la libreria requests para hacer peticiones HTTP a la API

## Pasos para ejecutar las pruebas:

pip install requests

pip install pytest

pytest create_kit_name_kit_test.py
